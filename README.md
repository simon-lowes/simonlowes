# Simon Lowes

Official website for Simon Lowes, an alternative rock musician, singer-songwriter, and guitarist.

**Live site:** [simonlowes.com](https://simonlowes.com)

## Features

- Three.js animated starfield background with parallax effect
- Glass-morphism UI design
- Integrated audio player
- Blog with Astro content collections
- Mobile responsive with reduced motion support

## Tech Stack

- [Astro](https://astro.build/) - Static site generator
- [Three.js](https://threejs.org/) - 3D graphics
- [GSAP](https://greensock.com/gsap/) - Animations
- [Vercel](https://vercel.com/) - Hosting
